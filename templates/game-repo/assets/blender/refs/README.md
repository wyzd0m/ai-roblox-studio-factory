# Reference images

Drop reference images for a model here (screenshots, concept art, photos of the target shape) before
asking Claude to build it. Claude reads them to shape the `bpy` script — this is the single biggest
accuracy lever for organic/creature meshes.

- Name them for the model: `rat-ceo-front.png`, `rat-ceo-side.png`, `grocery-shelf.png`.
- Front + side views help most for anything that isn't a simple box.
- Keep them committed so the model's provenance and intent are visible to reviewers.
