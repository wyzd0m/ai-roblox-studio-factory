---
Prepare <GAME_NAME> for release. Do NOT publish or upload anything.

1. Run the mechanical gate (`docs/DEFINITION_OF_DONE.md`) and report results honestly.
2. Complete every item you can in `standards/RELEASE_CHECKLIST.md`; list what remains for the human
   (playtest sign-off, publishing, YouTube upload).
3. Finalize README (all sections incl. AI disclosure), CHANGELOG (tag a version), and generate the
   YouTube metadata set into `video/`.
4. Add/update the entry in the factory's `games/REGISTRY.md`.
5. Summarize: what's done, what's blocked on the human, and any risks.

Stop at the publish gate — publishing and uploads are human-only.
